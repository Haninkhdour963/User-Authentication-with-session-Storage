# FoodMart & User Registration Web Pages

## Overview
This repository contains two separate but related web pages for a FoodMart application ecosystem:

1. **User Registration Page**  
   A responsive registration form designed to allow users to create an account with username, email, and password inputs. The page utilizes Bootstrap 5 for styling and layout, Swiper for potential carousel features, and includes integration for cryptographic operations using CryptoJS.

2. **FoodMart Dashboard Page**  
   An administrative dashboard interface for managing FoodMart product listings. It includes a form to add new products by category, name, price, and image URL, along with a dynamic table displaying product entries. The dashboard is styled with Bootstrap 5 and uses Font Awesome icons for enhanced UI elements.

---

## Features

### User Registration Page
- Responsive design using Bootstrap 5 grid system.
- Form fields for username, email, and password with client-side validation.
- Styled with Google Fonts (`Nunito`, `Open Sans`) for modern typography.
- External libraries included: Swiper (carousel), CryptoJS (for cryptography), jQuery.
- Modular JavaScript includes (`plugins.js`, `script.js`, `register.js`) for extensibility.

### FoodMart Dashboard
- Product management form with dropdown for categories and inputs for product details.
- Dynamic table to display product data with ID, category, name, price, image URL, and actions.
- Styled with Bootstrap 5 and custom CSS for improved UX.
- Footer with copyright.
- JavaScript files for handling form submission and admin logout.

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- Local or remote HTTP server to serve the files (optional but recommended for full JS functionality)

Usage
Use register.html for user registration functionality.

Use dashboard.html for managing FoodMart product listings.

JavaScript handles form validation, submission, and dynamic UI updates.

Customize CSS and JavaScript files to extend functionality.
